# <img src="../logo.png" alt="logo" style="zoom:60%;" /> 欢迎来到 ZJUCSSU

我们是浙江大学计算机科学与技术学院学生会，一个致力于服务同学、连接师生、促进交流的学生组织。

ZJUCSSU是一个由浙江大学计算机科学与技术学院学生会为服务全体计算机学院同学所搭建的网页。

我们在这个网页中分设了四个分区，以下是这四个分区的简要介绍。点击下方标题可快速跳转到对应板块。

## [通知中心](../Notification/index.md)

包括但不限于学生会活动、学院重要通知以及同学们分享的笔记或项目。点击上方标题进入 **通知中心** 查看最新通知。

## [知识共享](../知识共享/index.md)

我们会提供一些成熟的、经审核的资料供大家学习，比如课程相关笔记、经验，以及课外优质课程的链接与资源等。点击上方标题进入 **知识共享** 概览页。

## [答疑解惑](../答疑解惑/index.md)

作为同学与学院之间的窗口，可供同学们发表各种意见和提问，我们在看到后会及时回应。点击上方标题进入 **答疑解惑** 概览页。

现在同学们可以直接点击右边去反馈！[点我反馈！](https://www.wjx.cn/vm/wc5HPAS.aspx "完全匿名哦")

## [关于我们](index.md)

作为连接同学与学院的桥梁，我们致力于汇总信息、发布通知，并展示学院动态与风采。点击上方标题进入 **关于我们** 概览页。


这个网站目前仍在建设中。如有任何关于网站搭建的意见，欢迎通过提交 ISSUE或任何可以联系到我们的方式告知，我们会努力为大家提供一个全面、丰富的平台，给同学们的学习生活带来便利。
