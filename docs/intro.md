# 网站介绍与使用指南

本页面帮助新同学快速了解本站结构，并上手使用各项功能。

---

## 网站简介

本站由**浙江大学计算机科学与技术学院学生会**搭建，面向全体计算机学院同学，用于发布通知、收集反馈、共享学习资源与展示个人笔记与项目。我们希望通过这一平台，方便大家获取学院信息、参与意见反馈，并形成互助互学的学习氛围。

---

## 四大板块一览

本站分为四个主要板块，**点击板块名称可进入该板块的概览页**，再通过概览页中的表格链接或左侧导航进入具体内容。

| 板块 | 用途 | 入口 |
|------|------|------|
| [通知中心](Notification/index.md) | 学院与学生会各类通知汇总：教学事务、就业发展、科研动态、对外交流、评奖评优、文体活动、校园信息、思想成长等 | [通知中心概览](Notification/index.md) |
| [意见反馈](意见反馈/index.md) | 向学院与学生会提交意见、提问或吐槽，我们会及时回复并同步到网站 | [意见反馈概览](意见反馈/index.md) |
| [知识共享](知识共享/index.md) | 经审核的课程笔记、培养方案、课外学习资料与优质课程链接 | [知识共享概览](知识共享/index.md) |
| [资源分享](资源分享/index.md) | 同学们上传的个人笔记与项目展示区，优秀内容经审核后可进入知识共享区 | [资源分享概览](资源分享/index.md) |

## 如何快速上手

### 1. 使用顶部导航

页面**顶部**有 **主页 / 通知中心 / 意见反馈 / 知识共享 / 资源分享** 等标签。点击任一标签会进入对应板块的**概览页**，再通过概览页中的分类链接或左侧目录进入具体页面。

### 2. 使用左侧目录

进入某个板块后，**左侧**会显示该板块下的子分类（如通知中心下的「教学事务」「就业发展」等）。点击子项即可跳转到对应页面，无需每次都回到概览页。

### 3. 使用搜索

站点支持**全文搜索**。在页面顶部的搜索框中输入关键词，可快速定位到相关页面。

## 常用操作速查

### 我想查通知（选课、招聘、奖学金、活动等）

进入 **[通知中心](Notification/index.md)**，在概览页按分类找到对应入口（如「教学事务」「就业发展」「评奖评优与资助」等），或直接在左侧目录中点击子分类。

!!! tip "小提示"
    通知标题左侧的圆点**变暗**表示该通知已截止。若某条通知点进去显示「404 - Not Found」，表示该条暂无具体链接。

### 我想提意见、提问或吐槽

- **通过 GitHub Issue**（推荐）：在 **[意见反馈](意见反馈/index.md)** 中打开 [如何提交 ISSUE](意见反馈/ISSUE.md)，按教程在标题前加 `[意见]` / `[提问]` / `[吐槽]` 后提交即可，我们会评论回复并同步到网站。
- **匿名问卷**：也可使用主页上的 [点我反馈！](https://www.wjx.cn/vm/wc5HPAS.aspx "完全匿名哦") 链接进行完全匿名反馈。

### 我想找学习资料（培养方案、课程笔记、课外资源）

进入 **[知识共享](知识共享/index.md)**，可查看：

- **培养方案**：各专业（计科、软工、信息安全、工业设计、人工智能）培养方案与课程体系；
- **课程学习**：课程笔记、题库与学习资料；
- **课外学习**：课外笔记与优质在线课程、学习平台推荐。

### 我想分享自己的笔记或项目

进入 **[资源分享](资源分享/index.md)**，可查看「个人笔记」「个人项目」的说明与展示。提交方式有两种（任选其一）：

1. **邮件**：将笔记或项目发至 **zju_cssu@163.com**，在正文中写明姓名、联系方式、简短描述与展示意愿；
2. **GitHub**：按 [提交指南](资源分享/提交指南.md) 中的步骤 Fork 仓库、创建分支、添加文件并提交 Pull Request。

经审核通过后，内容会出现在资源分享区，优秀笔记还有机会被选入知识共享区。
